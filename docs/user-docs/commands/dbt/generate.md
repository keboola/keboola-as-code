# Generate Command

**Work with dbt inside your repository.**

The commands must be run in a directory with a dbt project (i.e., containing `dbt_project.yml`) or its subdirectory.

```
kbc dbt generate [command]
```

|---
| Command | Description
|-|-|-
| [kbc dbt generate profile](generate/profile.md) | Generate profiles for use with dbt. |
| [kbc dbt generate sources](generate/sources.md) | Generate sources for use with dbt. |
| [kbc dbt generate env](generate/env.md) | Generate environment variables for use with dbt. |
