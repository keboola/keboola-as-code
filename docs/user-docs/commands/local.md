# Local Command

**Operations in the [local directory](../structure.md) don't affect the project.**

```
kbc local [command]
```

|---
| Command | Description
|-|-|-
| **[kbc local create](local/create.md)** | **Create an object in the local directory.** |
| [kbc local create config](local/create/config.md) | Create an empty [configuration](https://help.keboola.com/components/). |
| [kbc local create row](local/create/row.md) | Create an empty [configuration row](https://help.keboola.com/components/#configuration-rows). |
| | |
| [kbc local persist](local/persist.md) | Detect new directories with a [configuration](https://help.keboola.com/components/) or a [configuration row](https://help.keboola.com/components/#configuration-rows). |
| [kbc local encrypt](local/encrypt.md) | Encrypt all [unencrypted secrets](https://help.keboola.com/extend/common-interface/config-file/#encryption). |
| [kbc local validate](local/validate.md) | Validate the local directory. |
| [kbc local fix-paths](local/fix-paths.md) | Ensure that all local paths match [configured naming](../structure.md#naming). |
