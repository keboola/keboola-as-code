# Create Local Object

**Create an object in the [local directory](../../structure.md).**

```
kbc local create [config/row] [flags]
```

Or shorter:
```
kbc create [config/row] [flags]
kbc c [config/row] [flags]
```

Shows an interactive dialog if you do not enter a sub-command.

|---
| Command | Description
|-|-|-
| [kbc local create config](create/config.md) | Create an empty [configuration](https://help.keboola.com/components/). |
| [kbc local create row](create/row.md) | Create an empty [configuration row](https://help.keboola.com/components/#configuration-rows). |
