# File Commands

**Manage [files](https://help.keboola.com/storage/files/) directly in the [project](../../README.md#subsystems).**

```
kbc remote file [command]
```

|---
| Command | Description
|-|-|-
| [kbc remote file download](file/download.md) | Download a [file](https://help.keboola.com/storage/files/) from Storage. |
| [kbc remote file upload](file/upload.md) | Upload a [file](https://help.keboola.com/storage/files/) to Storage. |
