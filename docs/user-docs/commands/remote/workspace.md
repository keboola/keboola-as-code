# Workspace Commands

**Manage workspaces directly in the [project](../../README.md#subsystems).**

```
kbc remote workspace [command]
```

|---
| Command | Description
|-|-|-
| [kbc remote workspace create](workspace/create.md) | Create a workspace in the project. |
| [kbc remote workspace delete](workspace/delete.md) | Delete a workspace in the project. |
| [kbc remote workspace detail](workspace/detail.md) | Print workspace details and credentials. |
| [kbc remote workspace list](workspace/list.md) | List workspaces in the project. |
